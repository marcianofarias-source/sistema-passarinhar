# Passarinhar Visitas Web 2.1

## Executar no VS Code
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Terminal > Novo Terminal.
4. Execute `npm install`.
5. Execute `npm start`.
6. Abra http://localhost:3000
